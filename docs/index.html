Installation Guide

安裝教學：4 個階段開始使用

依序準備工具、安裝 SideStore、下載 UFOGeo IPA，再完成 iOS 首次啟動設定。

STEP 01

首次準備工具

準備一台 Mac 或 Windows 電腦、一台 iOS 裝置，以及下列工具。

  • Mac：下載 iLoader DMG
  • Windows：iTunes、iLoader EXE 或 MSI。
  • iOS：安裝 LocalDevVPN，並開啟「開發者模式」。
STEP 02

安裝 SideStore

用 iLoader 與自己的 iPhone 完成配對，再安裝 SideStore。

  1. 安裝並開啟對應的 iLoader。
  2. 登入 Apple ID，與 iPhone 完成配對。
  3. 選擇安裝 SideStore (每夜建置)。
STEP 03

安裝 UFOGeo IPA

在 iOS 執行 SideStore

  1. 前往「設定 → 一般 → VPN 與裝置管理」，信任簽署開發者憑證。
  2. 開啟 LocalDevVPN，點選 Connect。
  3. 開啟 SideStore 點選右下角 Settings ，登入 Apple ID。
  4. 安裝最新 UFOGeo IPA。
STEP 04

首次在 iOS 執行

完成信任、VPN 與安裝 UFOGeo 後，即可開始定位測試。

  1. 開啟 UFOGeo，在匯入配對檔案的位置選擇 → 右下角瀏覽 → SideStore → 點選ALTPairingFile.mobiledevicepairing。
  2. Wi-Fi 可直接使用；行動數據若連線異常，先開關一次行動數據或飛航模式。

iOS 使用前提醒

請開啟「開發者模式」。使用行動數據時，如連線異常，README 建議先開關一次行動數據或飛航模式，再進行測試。

Privacy First

清楚說明每一類資料的用途

配對與模擬資料保留在裝置；會員與訂閱功能則分別使用 Firebase 與 Portaly，並只處理提供服務所需的資料。

🔒

不將敏感資料上傳至開發者伺服器

Pairing file、收藏位置與模擬路線不會上傳至開發者控制的伺服器。

HealthKit 步數操作直接透過 Apple HealthKit 完成，不會把健康資料上傳至 UFOGeo 後端。

解除安裝 UFOGeo 時，App 沙盒內保存的 pairing file 與相關資料會一併移除。

👤

會員與付款資料

Firebase Authentication 處理帳號 Email、UID 與登入驗證；UFOGeo 後端保存會員資格所需的 Email、UID 及訂閱狀態。

訂閱時，Portaly 會處理 Email、方案與付款資料；UFOGeo 不接觸完整卡號，只保存訂閱狀態、交易識別碼及必要稽核資料。
