01

適用範圍、維護者與日期

  • 本政策適用於 UFOGeo iOS App、UFOGeo 網站、帳號操作頁、付款結果頁，以及由 UFOGeo 引導至 Portaly 的訂閱結帳與管理流程。
  • 維護者：本服務由 Leoohyeah 的 UFOGeo GitHub 專案維護。如需聯絡，請使用第 8 節列出的支援信箱。
  • 本版本生效／更新日期：2026 年 9 月 2 日；本頁這一版自該日起適用。
  • Apple、Google Firebase、Portaly、GitHub 及其他第三方服務各自的服務，受其自己的條款與隱私政策約束；本政策只說明 UFOGeo 目前可控制或可確認的處理方式。
02

資料類別、來源與用途

  • 帳號資料：你在 App 輸入的 Email 與密碼，以及 Firebase 產生的 UID、Email 驗證狀態和登入權杖。用於註冊、登入、驗證信箱、重設密碼及保護帳號；UFOGeo 不保存明文密碼。
  • 訂閱與交易資料：帳號 Email、Firebase UID、方案與 Portaly 模式、結帳／訂閱／訂單識別碼、訂閱狀態、金額、幣別、付款識別碼或參考號、付款方式、時間戳、續訂／取消日期及必要的錯誤與安全稽核欄位。用於建立及恢復訂閱、避免重複訂單、同步 Pro 權限、退款或爭議處理、刪除帳號及防詐。
  • 免費 Pro 授權資料：後端以 Firebase UID 為 key 保存免費或期限 Pro grant 的 kind、active、到期時間、授予時間、授予者、原因，以及撤銷時間／撤銷者等欄位。這些資料用於判定 Pro 授權、授予或撤銷、防濫用與安全稽核；App 不直接寫入這些資料。
  • 本機裝置與檔案資料：你選取的 pairing file、其中的裝置憑證／私密金鑰、裝置 IP、收藏位置、搜尋／位置歷史、路線名稱與座標、匯入的路線內容及模擬設定。來源是檔案選擇器、你的輸入或 iOS 定位；用於連接你指定的已配對 iPhone、地圖顯示、定位模擬與路線模擬。
  • 位置與地圖資料：在你授權後取得的目前位置、你輸入或匯入的座標，以及地點搜尋文字。用於選擇起點、地圖搜尋、反向地理編碼與模擬定位；目前沒有將這些資料上傳至 UFOGeo 後端的功能，但 Apple 的 MapKit／定位服務可能會為提供其服務而處理相關查詢或座標。
  • 健康資料：App 會請求 Apple HealthKit 的步數讀取與寫入權限。目前實作只查詢授權狀態並將模擬產生的步數樣本寫入 HealthKit，不會把 HealthKit 步數內容上傳或保存至 UFOGeo 後端。
  • 技術與服務紀錄：Firebase、Hosting、Portaly、Apple 或 GitHub 可能因提供服務、安全、防濫用、除錯或更新查詢而處理 IP 位址、裝置／瀏覽器資訊、請求時間、錯誤及網路紀錄；這些資料的保存依各服務提供者政策。
03

本機與 UFOGeo 後端的界線

  • Pairing file、路線檔、收藏、位置／搜尋歷史、模擬路線與本機設定保存在 App 沙盒或 UserDefaults；登入權杖與訂閱狀態快取保存在此裝置的 Keychain，並設定為不可轉移至其他裝置。
  • Pairing file 只在本機讀取並傳給你指定的已配對 iPhone 或 LocalDevVPN／區域網路連線，以建立配對通道與設定模擬定位；不會傳到 UFOGeo Firebase 後端。座標也可能透過同一條本機／VPN 連線送至該 iPhone。
  • 路線檔會由 App 在本機解析；目前沒有把 pairing file、路線檔、收藏、完整位置歷史或 HealthKit 內容上傳至 UFOGeo 後端的功能。
  • Firebase 後端只在帳號、訂閱、結帳、回呼同步與刪除會員等流程處理必要的身分及交易資料；Firestore 不開放 App 直接讀寫。
  • 本機資料與帳號資料是兩個界線：在 App 內刪除會員不會自動刪除 pairing file、收藏、路線、位置歷史或已寫入 Apple Health 的步數。
04

權限與你的選擇

  • 定位：「使用 App 期間」用於取得目前位置；「永遠」只在你啟用背景定位／模擬而需要時使用。可在 iOS「設定」中撤回或調整，撤回後相關功能可能無法使用。
  • 區域網路：用於透過區域網路或 LocalDevVPN 與已配對 iPhone 通訊。你可以拒絕；拒絕後裝置連線與模擬功能會受限。
  • HealthKit：步數讀取／寫入權限由 Apple Health 管理。你可在「設定」或 Health App 撤回；撤回不會自動刪除已存在的 HealthKit 樣本。
  • 通知：只用於背景模擬或步數寫入結果的本機通知。你可在 iOS「設定」中關閉通知。
  • 檔案：只有在你使用系統檔案選擇器並選取檔案時，App 才讀取該檔案。UFOGeo 目前不要求相機、麥克風、通訊錄或照片權限。
  • UFOGeo 目前沒有自行整合廣告、跨服務追蹤、行為分析或 App 內廣告 SDK，也不以提供定位、通知或 HealthKit 權限作為付款條件。
05

第三方服務與跨境處理

  • Google Firebase：Firebase Authentication、Cloud Functions、Firestore 與 Hosting 用於帳號、後端 API、訂閱狀態及網站。請參閱 Firebase Privacy and Security 與 Google 隱私權政策。
  • Portaly：託管結帳、訂閱管理、續訂／取消及付款回呼。UFOGeo 將必要的 Email、方案、UID metadata、訂單／結帳識別碼送至 Portaly；目前整合不會讓 UFOGeo 取得完整卡號，完整付款資料由 Portaly 及其付款處理商依其流程處理。請參閱 Portaly Privacy Policy。
  • Apple：Core Location、MapKit、Apple 地圖／地點搜尋、反向地理編碼、HealthKit 及 iOS 權限服務。請參閱 Apple 隱私權政策。
  • GitHub：App 會查詢公開 Release 以檢查更新，網站提供 GitHub 原始碼與 Release 連結；GitHub 可能處理標準網路請求資訊。請參閱 GitHub Privacy Statement。

UFOGeo 僅在提供本政策列明功能所必要的範圍向上述接收方傳送資料，並要求接收方依適用法規、其公開的隱私／安全承諾及不低於本政策與 Apple 適用規範的保護標準處理；UFOGeo 不會另行將資料提供給未列明的第三方作廣告或跨服務追蹤。這項承諾限於 UFOGeo 可控制的資料分享；第三方對其自身服務收集或產生的資料仍依其政策與適用法律處理。

Firestore 與 Cloud Functions 目前設定在 Google Cloud 的 asia-east1 區域；Firebase Authentication、Hosting、Apple、Portaly、GitHub 及其服務商可能在其他司法管轄區處理技術或交易資料。跨境處理、服務商及保存方式依各提供者當時的政策與適用法律辦理。

06

網站、Cookie 與網路紀錄

  • UFOGeo 公開網站目前是靜態頁面，沒有由 UFOGeo 自行加入廣告或分析 Cookie。Firebase Hosting 仍可能為提供網站、偵測濫用及產生服務紀錄而處理 IP 與技術資訊。
  • 帳號驗證、重設密碼及恢復 Email 的操作頁會載入 Firebase Authentication 網頁程式庫；瀏覽器或 Firebase 可能使用必要的 Cookie、Local Storage 或類似技術，實際方式依 Google/Firebase 政策及你的瀏覽器設定。
  • Portaly 託管結帳與訂閱管理頁面不由 UFOGeo 控制，可能使用 Cookie、Local Storage 或分析技術；請依 Portaly 頁面與其隱私政策管理。
  • 帳號操作連結可能包含一次性驗證碼（例如重設密碼或驗證 Email 的 URL 參數）。請勿轉寄、截圖公開或張貼到公開空間；若連結外洩，請回到 App 重新取得操作連結。
07

保存、刪除與帳號結束

  • Pairing file：App 目前沒有刪除 pairing file 的按鈕；重新匯入會以新檔案替換 App 沙盒中的副本。若要移除 App 保存的副本，請刪除 App；原始檔案在「檔案」App 或其他來源位置，不會因替換或刪除 UFOGeo 自動刪除。
  • 收藏、位置歷史與已儲存路線：可在 App 對應列表使用刪除、全部清除或刪除路線的功能；刪除 UFOGeo 會員本身不會自動清除這些資料。
  • 裝置 IP 與其他模擬設定：保存在本機偏好設定；目前沒有通用的「清除全部本機資料」按鈕，這些資料會留在裝置直到透過可用設定變更，或刪除 App。
  • 登入權杖與訂閱快取保存在 Keychain；登出或刪除會員時，App 會清除 UFOGeo 的本機登入／訂閱快取。Keychain 的最終移除行為仍受 iOS 系統規則影響。
  • 在 App 選擇「刪除會員」後，後端會先嘗試停止該 Email 下仍可續訂的 Pro 訂閱，再刪除 Firebase Authentication 帳號與主要使用者文件。若付款結果尚未確認、仍有待完成 checkout，或無法確認／停止所有訂閱，系統可能暫時阻止刪除，以避免重複扣款；此時帳號不會被假裝刪除。
  • 帳號刪除 transaction 會一併刪除以該 Firebase UID 為 key 的 Pro grant 主文件；為了安全、防濫用、處理爭議及稽核，append-only 的 grant audit 可能依實際所需保留 UID、動作、授權 kind、操作者、原因與時間。UFOGeo 不承諾固定的保存期限。
  • 為處理回呼重播、退款、交易爭議、防詐、稅務／會計及安全稽核，checkout session、Portaly audit、鎖定及交易紀錄可能在帳號刪除後保留必要欄位。刪除流程會移除主要帳號文件及 session 中的部分 Email、UID、結帳 URL、token 等敏感欄位，但目前 backend 的 audit／交易紀錄仍可能保留 UID、訂單／訂閱／付款識別碼、金額、狀態與時間戳；本專案沒有承諾固定保存天數。
  • Portaly 端的付款、發票、退款及訂閱紀錄不會因 UFOGeo 刪除會員而自動消失，仍依 Portaly 及其付款處理商的政策與法定義務保存。已寫入 Apple Health 的步數樣本也不會因刪除 UFOGeo 會員或移除 App 而自動刪除。
  • 除服務商公開政策所述的技術紀錄外，UFOGeo 不宣稱超出實際設定的保存期限；保存期限會以完成目的、處理爭議、安全需求及適用法律所需的期間為限。
08

你的權利與如何提出請求

依你的所在地及適用法律，你可能有權查詢、閱覽、取得副本、更正、刪除、限制或反對處理、撤回同意、要求資料可攜，以及向主管機關申訴。你也可以在 iOS 設定撤回定位、區域網路、通知或 HealthKit 權限，在 Health App 管理已寫入的步數，或在 Portaly 管理訂閱、付款方式與付款紀錄。

若要詢問 UFOGeo 的資料處理、提出帳號刪除／資料權利請求或回報安全問題，請寄信至 leoohyeah.app@gmail.com 聯絡專案維護者。來信請說明請求類型與必要資訊；請勿提供密碼、完整付款卡號、登入權杖、一次性驗證碼、pairing file 或私密金鑰。如需核對帳號，維護者會另行說明最少必要的驗證資料。Portaly 或 Apple 保存的資料，應依其服務提供的請求管道提出。

09

未成年人

UFOGeo 不是以兒童為對象的服務。專案目前沒有在程式或公開資料中設定獨立的最低年齡門檻；未成年人使用前應取得法定監護人同意，並遵守所在地對帳號、位置、健康及付款資料的規定。若監護人認為我們收到未成年人資料，請寄信至 leoohyeah.app@gmail.com，且只提供處理請求所需的最少資料。

10

安全措施與限制

  • UFOGeo 的遠端帳號與後端請求使用 HTTPS；登入／訂閱權杖使用此裝置限定的 Keychain，pairing file 以 iOS 檔案保護、受限檔案權限並排除備份保存。
  • Firestore 由後端驗證後存取，付款 callback 必須經 Portaly 簽章驗證；UFOGeo 不保存完整卡號。
  • 我們會採取合理的技術與管理措施，但沒有任何網路傳輸、裝置或雲端儲存能保證絕對安全。若你發現 pairing file、登入連結或 token 外洩，請立即撤銷相關權限、重新匯出配對檔，並寄信至 leoohyeah.app@gmail.com 回報。
11

政策變更

服務、資料流程或適用法律變更時，本政策可能更新。我們會在本頁更新版本日期並公布新版內容；重大變更如依法需要額外通知，會依可用且適當的方式處理。請在繼續使用前檢視本頁；若不同意更新內容，請停止使用相關功能並依上方方式提出資料請求。
